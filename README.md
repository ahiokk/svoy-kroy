# Свой крой

Учебный прототип сайта магазина мужских джинсов «Свой крой». Сделан для практических занятий по дисциплине «Управление цифровым бизнесом» (РЭУ им. Г.В. Плеханова, 2026): установка счётчика Яндекс Метрики, цели, анализ посещаемости.

Товар не продаётся, заказы и персональные данные сайт не принимает. Фотографии сгенерированы нейросетью.
